# StarCity Builder

Портретный градостроитель на Rust, egui и wgpu. На карте 8 × 8 можно размещать дороги, дома, магазины и парки. Дома дают жителей, а дома, магазины и парки приносят доход. За строительство начисляется XP города и надетых питомцев.

Слева от карты открывается «Развитие города», справа — каталог яиц. Сохранены инвентарь, крафт, команды питомцев, покупка нескольких яиц, платная удача, улучшения, профиль и обе темы. Питомцы дают бонус к доходу. «Новый город» сбрасывает застройку и улучшения, сохраняя питомцев и уровень.

## Запуск

- Компьютер: `cargo run --bin starcity-builder`.
- Android: GitHub Actions собирает проверочный APK для ARM64. Для подписанного релиза и OTA нужны собственные секреты `STAR_CITY_KEYSTORE_BASE64` и `STAR_CITY_KEYSTORE_PASSWORD`. Подробности в [docs/OTA.md](docs/OTA.md).

Приложение использует отдельный Android-пакет `com.dozyfj.starcity` и собственные сохранения.
